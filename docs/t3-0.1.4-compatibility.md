# T3 Code 0.1.4 local candidate

This compatibility update is local and awaits manual acceptance. The published
Rasta 1.0.2 packages and signed feeds still target T3 Code 0.1.3.

The official Apple Silicon desktop ZIP was downloaded from the vendor's
[v0.1.4 release](https://github.com/pingdotgg/t3code/releases/tag/v0.1.4).
Its size is 179106790 bytes and its SHA-256 is
`d7458d6f833bf69a51b648c8ca55bd843c18a07f1687673248fb1940deeb8eb6`.
The download matches both the GitHub asset digest and the SHA-512 in
`latest-mac.yml`. Strict deep signature verification pins the vendor identity
`com.t3tools.t3code` and Team ID `ARK85ZXQ4Z`.

Both bundle version fields and the ASAR package version/buildVersion are
`0.1.4`; the embedded source commit is `783581d461dc`. The original entry point
is `apps/desktop/dist-electron/boot.cjs`. The client still contains the timeline,
message identity, user message and TipTap selectors used by Rasta.

Build the separate graphical installer with `ARTL_TARGET=t3` and
`ARTL_LOCAL_CANDIDATE=1` to test the embedded runtime without the published feed
selecting an older package. The source compatibility entry now targets 0.1.4;
Codex compatibility and both published feed URLs are unchanged.

The user must update T3 Code through its official updater, run the local Rasta
T3 Setup, and perform Launch and manual acceptance. Check Persian and English
messages, typed text, per-message directions, fonts, settings persistence and
normal app behavior. Automated checks do not establish manual acceptance.
Publishing an app package requires that acceptance and explicit GitHub
authorization.

Setup now identifies an older installed app from its compatibility requirement
even without a vendor update-feed response. On T3 0.1.3 it displays
"Update T3 Code first", the installed version, the required 0.1.4 version and
instructions to use T3's own updater before checking again. A newer unsupported
app still requires a compatible Rasta release rather than a downgrade.
The version label explicitly says "Rasta Setup 1.0.3" to distinguish the
installer version from the T3 version.
