# نصب و حذف

macOS 13.5+ و مک Apple Silicon لازم است؛ Node.js، sudo یا ورود به GitHub لازم نیست. نسخه‌های بررسی‌شده و لینک ZIP هر اپ در [README](../README.md) هستند.

۱. ZIP مربوط به [Codex](codex.md) یا [T3](t3.md) را باز و Setup همان اپ را اجرا کنید.
۲. Install/Update RTL و پس از آماده‌سازی **Launch** را بزنید؛ همان اپ دوباره باز می‌شود.
۳. تنظیمات از پنل Agent RTL در دسترس‌اند. **Remove RTL** و تأیید داخل پنل، همان اپ را بدون پچ دوباره باز می‌کند؛ حذف Setup به‌تنهایی پچ را حذف نمی‌کند.

حذف، runtime، تنظیمات و فونت‌های افزودهٔ همان target را پاک می‌کند؛ داده‌های اپ اصلی، اپ دیگر و Downloads حفظ می‌شوند. backup قدیمی روی نسخهٔ جدید اپ بازگردانده نمی‌شود.

## رفع مشکل

- بستهٔ آزمایشی notarization ندارد؛ پس از تلاش برای بازکردن، در **System Settings → Privacy & Security → Open Anyway** تأیید کنید؛ [راهنمای اپل](https://support.apple.com/en-us/102445).
- خطای دریافت یا صحت فایل: دوباره از همان انتشار دانلود کنید. فایل نامعتبر را اجرا نکنید.
- درخواست آپدیت اپ: ابتدا نسخهٔ رسمی اپ هدف را به‌روز کنید. **Check again** یعنی سازگاری یا دریافت اطلاعات هنوز تأیید نشده است.

## تست بستهٔ GitHub

ZIP منتشرشده را جدا از candidate محلی دریافت کنید؛ دریافت مرورگری و `install.sh` مخصوص Codex مسیرهای جدا هستند. یک بار پیش از Launch انصراف دهید؛ اپ نباید تغییر کند. سپس Launch را خودتان بزنید و ظاهر پنل، تایپ/ارسال، فونت، تم/رنگ، جهت پاسخ و ماندگاری پس از خروج کامل را بررسی کنید. حذف را یک بار لغو و سپس تأیید کنید؛ همان بسته دوباره قابل نصب باشد.
