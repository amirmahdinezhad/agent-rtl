The installed T3 Code bundle and ASAR still identify version/build `0.1.4`.
The new vendor bundle was inspected separately; no installed app was closed,
launched or replaced during preparation.

The official Apple Silicon ZIP comes from the vendor's
[v0.1.5 release](https://github.com/pingdotgg/t3code/releases/tag/v0.1.5).
Its size is 179252121 bytes and its SHA-256 is
`d6db5948b99264597f87c78f02dd0b08a7c526ef23cc8aaf135c14867baad568`.
The download matches the GitHub asset digest and the SHA-512 in `latest-mac.yml`.
Strict deep signature verification confirms `com.t3tools.t3code`, Team ID
`ARK85ZXQ4Z`.

Both bundle version fields and the ASAR version/buildVersion are `0.1.5`;
the embedded source commit is `6d450a428485`. The original entry point remains
`apps/desktop/dist-electron/boot.cjs`. The timeline, message identity, markdown
and TipTap selectors used by Rasta remain present. The compatibility catalog
now targets 0.1.5; older T3 installations must use the vendor updater first.
Codex compatibility and public stable feed URLs are unchanged.

The isolated staged bundle passes strict deep signature verification. All 1817
original JavaScript files remain byte-identical. The preview framework matches
the vendor framework before local signing, preserving its disabled integrity
setting. The real 0.1.5 stylesheet passes the T3 presentation smoke test for
mixed-language replies, RTL composition, code isolation, theme controls
and settings persistence.

## Manual panel update acceptance

Use the private development workflow described in
[development-workflow.md](development-workflow.md). Its signed private feeds
are separate from public Stable. Downloaded candidate packages must pass
independent hash and signature verification before manual testing.

1. Update T3 Code to 0.1.5 using its official updater.
2. If the previous Rasta runtime is removed by that update, use the separate
   local-only compatibility Setup prepared from the preceding private candidate.
   It retains that candidate's Rasta version while allowing T3 0.1.5. Initial
   Setup must install that previous runtime rather than upgrading to the new
   candidate. Select Launch yourself.
3. In the previous runtime's panel, select the authenticated owner's Beta
   channel. Close the panel and explicitly confirm the update dot.
4. Open the panel and select Check for updates (Refresh). Confirm it offers the
   intended new private candidate; select Download update and complete the
   in-panel upgrade, selecting Launch yourself.
5. Confirm the new Rasta version is displayed and T3 works normally, including
   Persian/English replies, composition, per-message directions and saved fonts.

Record these five panel observations separately from Setup acceptance and
separately for T3 and Codex. Automated checks do not establish manual acceptance.
Public promotion requires acceptance of the exact candidate and explicit GitHub
publication authorization. Repeat production-feed acceptance after promotion.
