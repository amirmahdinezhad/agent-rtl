# T3 Code

Agent RTL ۱٫۰٫۰ برای T3 Code (Beta) `0.1.3` روی macOS / Apple Silicon؛ با همان پنل و قابلیت‌های Codex.

۱. [ZIP مخصوص T3](https://github.com/amirmahdinezhad/agent-rtl/releases/download/v1.0.0/Agent-RTL-T3-1.0.0-darwin-arm64.zip) را باز و **Agent RTL T3 Setup.app** را اجرا کنید.
۲. Install/Update RTL و پس از آماده‌سازی **Launch** را بزنید؛ همان T3 دوباره باز می‌شود.
۳. RTL، فونت، تم، رنگ و جهت هر پاسخ را از پنل تنظیم کنید. جهت پاسخ‌ها به محیط، چت و شناسهٔ پاسخ متصل است.

تنظیمات، فونت‌ها، runtime و backup: `~/Library/Application Support/Agent RTL T3/`؛ مستقل از Codex. **Remove RTL** همان T3 اصلی را دوباره باز می‌کند؛ Codex و Downloads دست‌نخورده می‌مانند. backup قدیمی روی نسخهٔ جدید اپ بازگردانده نمی‌شود.

بسته و manifest امضاشدهٔ T3 مستقل‌اند؛ بستهٔ Codex به‌عنوان آپدیت T3 پذیرفته نمی‌شود. نصب امضای محلی اپ را جایگزین می‌کند؛ Touch ID/passkey و پنجرهٔ جدا هنوز تأیید جزئی کاربر ندارند.

ساخت محلی: `ARTL_TARGET=t3 ARTL_LOCAL_CANDIDATE=1 npm run build:gui`.
