# T3 Code

Agent RTL 1.0.1 for T3 Code (Beta) `0.1.3` on macOS / Apple Silicon, with the same panel and features as Codex.

1. Extract the [T3 ZIP](https://github.com/amirmahdinezhad/agent-rtl/releases/download/v1.0.1/Agent-RTL-T3-1.0.1-darwin-arm64.zip) and open **Agent RTL T3 Setup.app**.
2. Choose Install/Update RTL, then **Launch** after preparation. The same T3 app reopens.
3. Adjust RTL, fonts, theme, accent and per-response direction in the panel. Response direction is scoped to environment, chat and response ID.

Settings, fonts, runtime and backups: `~/Library/Application Support/Agent RTL T3/`, independent of Codex. **Remove RTL** reopens the original T3 app and preserves Codex and Downloads. An old backup is never restored over a newer app version.

T3 has its own signed package and manifest; a Codex package is not accepted as a T3 update. Installation replaces the app's local signature. Touch ID/passkeys and detached windows still lack detailed user acceptance.

Local build: `ARTL_TARGET=t3 ARTL_LOCAL_CANDIDATE=1 npm run build:gui`.
