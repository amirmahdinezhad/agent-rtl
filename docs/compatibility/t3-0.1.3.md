# T3 Code (Beta) 0.1.3 — Agent RTL 1.0.0

Review environment: macOS / Apple Silicon; app `/Applications/T3 Code (Beta).app`, package `t3code`, vendor commit `d2c440312e5f`.

The panel is shared with Codex. Direction keys include environment, chat and response ID; tool/user-message rows have no response controls. Separate wrapper/preload files preserve original ASAR bytes. The payload path is absolute to support reloads on nested routes.

T3's native integrity is disabled by the vendor and that state is preserved. Codex still requires active integrity. Signing and metadata are checked for both apps. T3 state, fonts, runtime, backups, jobs and manifests are independent; removing T3 does not remove Codex data.

General local-test acceptance was previously reported. An active T3 installation/job could not be matched when this report was recorded. Passkeys/Touch ID, detached windows and all removal/reinstallation states lack detailed acceptance. This report is not independent acceptance of the 1.0.0 package; actual GitHub installation/Launch requires separate verification.
