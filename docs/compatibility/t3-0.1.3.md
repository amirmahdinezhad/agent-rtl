# T3 Code (Beta) 0.1.3 — Agent RTL 1.0.0

محیط بررسی: macOS / Apple Silicon؛ اپ `/Applications/T3 Code (Beta).app`، package `t3code`، vendor commit `d2c440312e5f`.

پنل مشترک با Codex است؛ کلید جهت شامل محیط، چت و شناسهٔ پاسخ است و ردیف ابزار/پیام کاربر کنترل پاسخ ندارند. wrapper/preload مستقل bytes اصلی ASAR را حفظ می‌کند؛ مسیر payload مطلق است تا reload مسیر تو‌در‌تو سالم بماند.

integrity بومی T3 از طرف سازنده غیرفعال است و همین وضعیت حفظ می‌شود؛ Codex همچنان integrity فعال می‌خواهد. امضا و metadata هر دو بررسی می‌شوند. state، فونت، runtime، backup، job و manifest T3 مستقل‌اند؛ حذف T3 دادهٔ Codex را پاک نمی‌کند.

قبولی کلی تست محلی قبلاً گزارش شده؛ هنگام ثبت، نصب فعال/job T3 قابل تطبیق نبود. passkey/Touch ID، پنجرهٔ جدا و تمام حالات حذف/نصب مجدد تأیید جزئی ندارند. این گزارش پذیرش مستقل بستهٔ 1.0.0 نیست؛ نصب/Launch واقعی GitHub جدا لازم است.
