# Agent RTL 1.0.0

- پنل RTL برای Codex `26.1023.50603` و T3 Code (Beta) `0.1.3`؛ بسته، تنظیمات و آپدیت مستقل هر اپ.
- فونت TTF/OTF، اندازه و فاصلهٔ خطوط، تم، چهار accent با Lavender پیش‌فرض، تاگل‌های سفید و جهت مستقل پاسخ‌ها.
- نمایش نسخه و خلاصهٔ آپدیت؛ حذف از داخل پنل و بازگشایی همان اپ، بدون دسترسی به Downloads.

برای macOS 13.5+ و Apple Silicon؛ بسته‌ها امضای محلی دارند و notarization اپل ندارند. Launch را کاربر انجام می‌دهد. قبولی کلی تست محلی هر دو اپ قبلاً گزارش شده؛ موارد جزئی از جمله passkey و تمام حالت‌های پنجرهٔ جدا تأیید مستقل ندارند. نصب/Launch واقعی این بسته از GitHub جدا باید تست شود.

شماره‌گذاری از 1.0.0 شروع شده است؛ کاربران نسخه‌های شماره‌گذاری قبلی، Setup جدید را دستی دریافت کنند.
